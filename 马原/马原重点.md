# 为什么人工智能不能有人的意识

1. 人工智能只是人类让其具有完成某种复杂任务的动力的机体，没有情感等人类意识形式
2. 人工智能不可能具备社会性
3. 人工智能无法完全理解自然语言
4. 人工智能只能接受能够被划约为数字信号的信息，而人的意识中很多东西都不能划约为数字信号（比如潜意识）

# 世界物质的统一性

1. 自然界是物质的
2. 人类社会也是物质的
3. 人类意识统一于物质
4. 世界的物质统一性原理是马克思主义最基本最核心的观点，是马克思主义的基石

# 事物的普遍联系

联系是指事物内部各要素之间和事物之间相互影响，相互制约，相互作用的关系

# 联系的特点

1. ## 联系具有客观性

   事物的联系是事物本身所固有的，不为人的意志所转移的

2. ## 联系具有普遍性

   1. 任何事物内部的不同要素之间都是相互联系的
   2. 任何事物都不能独立存在，一定与其他事物之间存在联系
   3. 整个世界是相互联系的统一的整体

3. ## 联系具有多样性

4. ## 联系具有条件性

   1. 条件是对事物存在和发展发生作用的诸要素的总和
   2. 条件对事物发展和人的活动具有支持和制约的作用
   3. 条件是可以改变的
   4. 改变和创造条件不是任意的，要遵循事物发展的一般规律

# 事物的变化和发展

1. 事物之间的相互联系构成了运动，变化和发展
2. 变化是指事物发生的一切改变
3. 发展则是指事物变化中前进的，上升的运动
4. 新事物的产生和旧事物的灭亡
5. 新事物是指符合历史前进方向，具有远大前途的东西
6. 旧事物是指丧失历史必然性，日趋灭亡的东西

# 新事物不可战胜的原因

1. 新事物适应了当下变化了的环境和条件，旧事物不适应
2. 新事物否定了旧事物中消极腐朽的东西，保留了新事物中合理的，适应新条件的因素

# 对立统一规律

1. 对立统一规律是唯物辩证法的核心
2. 对立统一规律揭示了事物普遍联系的根本内容和发展的内在动力
3. 贯穿量变与质变规律，否定之否定规律和唯物辩证法的中心线索
4. 提供了人们认识世界和改造世界的根本方法，矛盾分析方法

# 矛盾的同一性

1. 同一性是事物存在和发展的前提
2. 同一性使矛盾的双方各自吸取有利因素，在相互作用中得到发展
3. 同一性规定着事物转化的可能与发展的趋势

# 矛盾的特殊性

各个事物的具体矛盾，每一个矛盾在各个方面在发展的不同阶段上各有特点，矛盾的特殊性决定了事物的不同特征

# 量变和质变

1. 量变：事物数量的增减和组成要素排列次序的变动，是保持事物质相对稳定的不显著变化，体现了事物发展渐进过程的连续性
2. 质变：事物性质的根本变化，体现了事物发展渐进过程和连续性的中断

# 量变和质变的辩证关系

1. 量变是质变的必要准备
2. 质变是量变的必然结果，并为量变开辟道路
3. 量变和质变相互渗透，量变质变规律体现了事物发展过程渐进性和飞跃性的统一

# 否定的深刻内涵

1. 否定是事物的自我否定，自我发展，是事物内在矛盾运动的结果
2. 否定是事物发展的环节
3. 否定是新旧事物联系的环节
4. 否定的实质是扬弃，即新事物对旧事物既批判又继承，即克服消极因素又保留积极因素

# 前进与曲折

1. 前进性体现在每一次否定都是质变，都把事物推向新阶段
2. 曲折性体现在回复性上，其中暂时有停顿甚至倒退
3. 事物发展的前进性与曲折性在人类历史上得到体现

# 实践的几种类型

1. 物质生产实践（最基本）
2. 社会政治实践
3. 科学文化实践
4. 虚拟实践

# 实践与认识的关系

1. 实践是认识的来源
2. 实践是认识发展的动力
3. 实践是认识的目的
4. 实践是检验真理性的唯一标准

# 感性认识与理性认识

1. 感性认识是人们在实践基础上，由感觉器官直接感受到的关于事物的现象，事物的外部联系，事物的各个方面的认识
2. 感性认识包括感觉，知觉，和表象三种形式
3. 直接性和具体性
4. 理性认识是指人们使用抽象思维，以大量感性材料为基础，达到关于事物的本质，全体，内部联系和事物自身规律性的认知
5. 包括概念，判断，推理三种形式
6. 抽象性和间接性

# 感性认识与理性认识关系

1. 理性认识依赖于感性认识
2. 感性认识有待发展为理性认识
3. 感性认识与理性认识相互渗透，相互包含

# 从感性上升到理性的两个条件

1. 投身实践，获得十分丰富有效的感性材料
2. 经过思考的作用将丰富的感性材料加工，形成概念和理论的系统

# 真理

标志着主观和客观相符合的哲学范畴（客观性是本质属性）

# 真理的绝对性和相对性

1. 真理主客观统一的确定性和发展的无限性，承认了世界的可知性也就是承认了真理的绝对性
2. 人们在一定条件下对客观事物及其本质和发展的规律的正确认识总是有限度的，不完善的
3. 真理的绝对性和相对性的辩证统一，永远处在由真理的相对性走到绝对性，接近绝对性的转化和发展过程中

# 实践能够作为检验真理唯一标准的原因

1. 真理是主观与客观相符合的哲学范畴
2. 实践具有直接现实性，实践的直接现实性是其客观实在性的具体表现

# 实践作为检验真理唯一标准是确定性与不确定性的统一

1. 实践的标准的确定性即绝对性，是指实践作为检验真理唯一标准的绝对性
2. 实践标准的不确定性即相对性，是指实践作为检验真理标准的条件性

# 任何成功的实践都是合规律性和合目的性的统一

# 自由的条件

1. 认识条件：既要有对客观事物的正确认识，最主要的是对客观事物运动发展规律性，必然性的正确认识
2. 实践条件：既能够将获得的规律性认识用于指导实践，实现改造世界的目的

# 社会意识的相对独立性

1. 社会意识在从根本上收到社会存在决定的同时，还具有保持自身的发展形势和发展规律
2. 社会意识内部各种形式之间存在相互影响且各自具有历史继承性
3. 社会意识对社会存在具有能动的反作用，这是社会意识具有独立性的突出表现

# 生产关系的内涵

1. 生产关系包括生产资料所有制关系
2. 生产中人与人关系
3. 产品分配关系

# 生产力和生产关系的相互关系

1. 生产力状况决定生产关系的性质
2. 生产力的发展决定生产关系的变化
3. 生产关系适合生产力发展的客观要求时就会对生产力发展起到推动作用
4. 生产关系不适合生产力发展时就会阻碍生产力发展

# 经济基础和上层建筑

1. 经济基础是由社会一定发展阶段的生产力所决定的生产关系的总和
2. 上层建筑是建立在一定经济基础上的意识形态以及与之相适应的制度，组织和设施
3. 经济基础决定上层建筑
4. 上层建筑对经济基础具有反作用
5. 经济基础和上层建筑的相互作用构成了两者间矛盾运动
6. 经济基础与上层建筑的内在联系决定了上层建筑必须适合经济基础状况的规律

# 社会形态更替的特点

1. 统一性多样性
2. 必然性
3. 选择性

# 社会基本矛盾在历史发展中的作用

1. 生产力是社会基本矛盾运动中最基本的动力因素，是人类社会进步和发展的根本力量
2. 生产力是社会进步的根本内容，是衡量社会进步的根本尺度
3. 生产力与生产关系的矛盾决定着经济基础和上层建筑之间矛盾的产生和发展
4. 后者也会制约前者
5. 社会基本矛盾具有不同的表现形式和解决方式，并从根本上影响和促进社会形态的发展与变化

# 阶级斗争

1. 阶级斗争是社会基本矛盾在阶级社会中的表现
2. 是阶级利益根本冲突的对抗阶级之间的对立和斗争
3. 根源于社会经济关系的冲突
4. 是阶级社会更客观存在的必然现象，贯穿于阶级社会的全部发展过程
5. 推动作用表现在对社会形态的更替中，还表现在同一社会形态的量变中

# 人民群众在创造历史过程中的决定作用

1. 人民群众是社会物质财富的创造者
2. 人民群众是社会精神财富的创造者
3. 人民群众是社会变革的决定力量
